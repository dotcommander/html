Variant 03 / Field Notebook

A traced render observation

This direction treats generated HTML as a durable note: source evidence in the main column, implementation reminders in the margin.

Observation

The native semantic space is Markdown plus trusted local HTML. The rendered artifact is a single offline page, so every component must survive file URL loading and cache reuse.

Transform

actions.Run validates the source, decides freshness, limits reads, and delegates to render.Render. The resulting file is atomically written before the opener sees it.

Design implication: widgets must be CSS and inline-script friendly. No external sprite sheets, no CDN fonts, no build-time hydration assumptions.

Sample command

html -n goals.md
html -f goals.md
html --safe downloaded.md
Invariant

One self-contained HTML document.

Widget fit

Margin notes, small ledgers, and source cards are useful for long debugging writeups.

Avoid

Heavy dashboard chrome on ordinary prose.

Best for

Proof notes, architecture tracing, release investigation, and local research logs.
