Each variant treats the same CLI as a different product surface: quiet reader, operator console, notebook, API manual, review desk, and presentation brief. Choose the components and mood worth folding back into the embedded renderer.

Variant 05

Review Desk

Briefing Stage

Editorial, presentation-like rendering for summaries and decision memos.
